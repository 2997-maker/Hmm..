# Sansa DJ (사이버 산사 라운지) 기능 및 기술 명세서

---

## 1. 제품 비전 (Product Vision)

- **배경**: 2026년 10월 말, 대화나 경쟁 없이 말없이 모여 절하고 염주를 굴리며 힐링하는 웹서비스 '산사(SANSA)'가 일주일 만에 100만 명의 방문자를 모으며 바이럴이 됨.
- **가설**: 사람들은 음악을 혼자 듣기보다 "누군가 지금 실시간으로 틀어주는 음악을 다른 사람들과 함께 듣고 있다"는 느슨한 연대감(Ambient Co-presence)을 원함.
- **제품 정의**: 
  - DJ 부스 1명이 음악을 선곡/믹싱하고,
  - 불특정 다수의 관객이 로그인 없이 입장하여 작업/공부 배경음악으로 들으며,
  - 비트에 맞춘 헤드뱅잉, 야광봉, 합장 등 미니멀한 리액션만 주고받는 사이버 산사 리스닝 라운지.

---

## 2. 유저 페르소나 및 핵심 사용자 여정 (User Journey)

### 페르소나 A: 음악 틀어주는 호스트 (DJ)
1. 사이트에 접속해 "DJ 부스 콘솔" 탭을 선택한다.
2. 음악(유튜브/사운드클라우드 링크 또는 자체 신스)을 재생한다.
3. 필터(Lowpass)나 스크래치, 에어혼 효과음을 섞어 비트를 조절한다.
4. 플로어의 관객들이 야광봉과 하트를 띄우며 반응하는 모습을 보며 뿌듯함을 느낀다.

### 페르소나 B: 작업하며 듣는 리스너 (Audience)
1. 링크 하나로 접속 즉시 앰비언트 비트와 현재 트랙이 재생된다.
2. '나: 작은 솔잎' 같은 무작위 동자승/자연 닉네임이 부여된다.
3. 다른 아바타들과 나란히 서서 비트에 맞춰 고개를 끄덕인다.
4. 비트가 좋을 때 야광봉 버튼이나 합장 버튼을 눌러 화면에 작은 인터랙션을 남긴다.

## 3. 핵심 기능 요구사항 (Functional Requirements)

| 모듈 | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| **Audio** | 내장 신스 비트 | Web Audio API 기반 로파이 비트 생성 (오프라인/기본 재생) | P0 (완료) |
| **Audio** | 유튜브 스트림 연동 | YouTube Iframe API 기반 실시간 싱크 재생 | P1 |
| **Audio** | DJ FX 컨트롤러 | Lowpass 필터 노브, 스크래치 FX, 에어혼 | P0 (완료) |
| **Visual** | 네온 턴테이블 애니메이션 | 재생 상태에 따른 바이닐 회전 및 톤암 동작 | P0 (완료) |
| **Visual** | 비트 시각화 (Visualizer) | 오디오 진폭에 반응하는 네온 24바 비주얼라이저 | P0 (완료) |
| **Floor** | 산사식 아바타 플로어 | 접속자 아바타 그리드 + 비트 동기화 끄덕임(헤드뱅잉) | P0 (완료) |
| **Social** | 플로팅 리액션 | 야광봉, 드랍, 합장, 둠칫 클릭 시 화면 위로 부유 | P0 (완료) |
| **Sync** | 실시간 룸 동기화 | WebSocket / Supabase Realtime 기반 음악 타임코드 싱크 | P1 |
| **Queue** | DJ 릴레이 대기열 | 관객의 DJ 신청 및 곡 종료 후 자동 DJ 교체 | P2 |

## 4. 기술 스택 및 아키텍처 제안

- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas, Web Audio API, Modern CSS3 (Grid/Flex, Custom Properties). 번들러 없이 바로 서빙 가능.
- **Real-time Sync**: PartyKit 또는 Cloudflare Workers WebSocket / Supabase Broadcast.
- **Audio Source**: YouTube Iframe Player API (클라이언트 분산 로딩으로 서버 트래픽 0 유지).
