# ⛩️ Sansa DJ (사이버 산사 온라인 라운지)

> **"말없이 함께 비트 타는 온라인 DJ & 리스닝 라운지"**  
> 화제의 온라인 절 '산사(sansatemple.com)'의 무언·공존 힐링 감성을 온라인 디제잉으로 재해석한 프로젝트입니다.

---

## ✨ 핵심 컨셉

- 🎧 **실시간 1인 DJ + 다수 관객 리스닝 룸**: 호스트 DJ가 음악을 틀고, 관객들은 산사처럼 가입 없이 조용히 플로어에 서서 음악을 함께 듣습니다.
- 🪄 **산사식 미니멀 인터랙션**: 복잡한 채팅 없이 야광봉 흔들기, 둠칫 비트타기, 합장, 불꽃 반응 등 쫀득한 리액션만 플로어에 퐁퐁 띄웁니다.
- 🏮 **사이버 산사 비주얼**: 어둑한 네온 조명과 붉은 연등, 비주얼라이저, 회전하는 바이닐 턴테이블이 어우러진 감성적인 공간.
- ⚡ **Zero-Dependency MVP**: 번들러나 외부 라이브러리 없이 순수 HTML5/CSS3/Vanilla JS 및 Web Audio API로 구현되어 브라우저에서 바로 실행됩니다.

---

## 🖥️ 현재 구현된 기능 (MVP)

1. **Web Audio 내장 신디사이저**: 별도 MP3 파일 없이도 브라우저에서 로파이 드럼 킥/스네어/하이햇 및 코드 진행이 실시간 합성 재생.
2. **DJ 믹서 콘솔**: 재생/일시정지 토글, 바이닐 회전 & 톤암 애니메이션, Lowpass 필터 스위프 슬라이더, 턴테이블 스크래치 & 에어혼 FX.
3. **산사식 관객 플로어**: 동자승·자연 닉네임('나: 작은 솔잎', '달빛스님' 등) 아바타들이 비트에 맞춰 고개를 끄덕임.
4. **리액션 레이어**: 야광봉(🪄), 둠칫(🕺), 드랍(🔥), 합장(🙏) 클릭 시 플로팅 애니메이션 발생 (주변 접속자 랜덤 반응 시뮬레이션 포함).

---

## 🏃 로컬 실행 방법

```bash
# public 디렉토리에서 간단한 정적 웹서버 실행
python3 -m http.server 8000 --directory public
```
브라우저에서 `http://localhost:8000` 접속
